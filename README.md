## 🌟 Featured Project: Nobita's Room — 3D Interactive Portfolio

> An interactive first-person 3D WebGL developer portfolio inspired by **Nobita Nobi's iconic bedroom** from *Doraemon*. Zero heavy 3D asset downloads — the entire environment, textures, and spatial audio are generated procedurally in real-time.

<div align="center">
  <img src="public/assets/sanji.gif" width="260" style="border-radius: 8px;" alt="Anime Sanji" />
</div>

### 🎮 Interactive Highlights
- **First-Person Room Exploration:** Walk freely around Nobita's room with collision detection, wall sliding, and responsive mouse/touch look.
- **Retro Computer OS (`Finder`, `Terminal`, `Notes`, `Mail`):** Inspect live shipped projects, architecture graphs, and execute Unix-style terminal commands (`help`, `projects`, `skills`, `whoami`, `secret`).
- **Bookshelf of Skills:** Filter and pull books representing tech stack proficiencies across AI/ML, Systems, Backend, and Frontend.
- **Achievements Corkboard:** Interactive pinned cards chronicling hackathon victories, leadership roles, and research projects.
- **Doraemon's Secret Time-Machine Drawer:** Open the study desk drawer to reveal the secret dimensional gateway.
- **Dynamic Lighting & Time Cycle:** Switch between **Morning**, **Afternoon**, **Evening**, and **Night** with real-time shadow casting and ambient shifts.
- **100% Procedural Synthesized Audio:** Web Audio API synth generating dynamic footsteps, desk drawer sliding, lamp switches, and room drone without external MP3 files.
- **Guided Tour Mode & Accessible Direct View:** Seamless auto-guided camera tour for visitors who want a hands-free walkthrough.

## 🛠️ Tech Stack & Architecture

```
Three.js (Procedural 3D WebGL Scene)
      │
      ├── RoomCanvas.tsx ──────► First-person kinematics & AABB collision
      │
      ├── Zustand Store ───────► Finite State Machine & localStorage
      │
      ├── Procedural Textures ─► Pure HTML Canvas Generators (No GLB/PNG bloat)
      │
      ├── SoundManager ────────► Web Audio API procedural synthesis
      │
      └── React 19 Overlays ───► Computer OS, Skills Bookshelf, Modals
```

- **Frontend Framework:** React 19, TypeScript
- **3D Graphics Engine:** Three.js (RoomEnvironment, PMREMGenerator, PCFSoftShadowMap)
- **State Management:** Zustand 5
- **Styling:** Tailwind CSS v4
- **Audio:** Web Audio API Procedural Synthesizer
- **Bundler & Tooling:** Vite 8, Lucide React, Motion

## 🚀 Getting Started

### Prerequisites
- [Node.js](https://nodejs.org/) (v18 or higher recommended)
- `npm` or `bun`

### Installation

```bash
# 1. Clone the repository
git clone https://github.com/YeswanthRam28/YeswanthRam28.git
cd YeswanthRam28

# 2. Install dependencies
npm install

# 3. Start development server
npm run dev
```

Visit `http://localhost:3000` in your browser.

### Build for Production

```bash
# Type check and build
npm run lint
npm run build

# Preview production bundle
npm run preview
```

### Run Tests

```bash
npx tsx src/game/rules.test.ts
```
